# Screenshots

Screenshots of the real Sudo Make Art desktop app (Linux, built from this repository), used in the main README. The projects in them (the night market poster, the café logo, the slime sprite and so on) are sample content made only for these pictures: shapes, text and pixels, with no third-party artwork. The avatar and manga characters are the app's own built-in character maker, not anyone's model. The video editor shows a generated gradient clip.

The window is shown at the size it was captured, then scaled down for the README.
